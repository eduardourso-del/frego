# Exploração is not the Clube

The installed app keeps calling `/me/memberships` and `/me/wallet`, and those responses stay the list of Clubes she already belongs to. Tab position is superseded by ADR 0014. Visível is its own flag, off until an operator turns it on, because Suspenso also blocks the till. Favorito is its own mark, not a membership, because hearting a place must not open a Clube or start avisos. A Clube created later keeps that mark.
