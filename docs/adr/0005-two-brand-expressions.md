# Two brand expressions, one interface

The October 2026 identity replaces the provisional August palette. Freguês surfaces frame the mark in Céu Azul; lojista surfaces frame it in Grafite. Both share Papel, Mostarda for the action, the same type families, and the same components. A shop's own color stays on the shop's mark and does not tint Frego chrome.

One blue for every product would erase the split the identity specifies. A second component system per audience would duplicate the interface the guide says not to duplicate.
