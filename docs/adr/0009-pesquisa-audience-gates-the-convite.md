# Audiência gates the Convite, not the Resposta

A Pesquisa with an Audiência opens a Convite only for a Cliente who matches it on that earn. No Audiência means every Cliente. The page she already has open still submits, even if a later earn falls outside the Audiência or the Audiência is edited. Deleting the Audiência leaves the Pesquisa open to every Cliente.

We rejected checking the Audiência again at submit, and closing an open Convite when she no longer matches.
