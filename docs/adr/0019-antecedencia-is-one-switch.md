# Antecedência is one switch for the wallet Lembrete

Validade is already chosen per wallet, and the Lembrete used one 7-day window for every Estabelecimento. Antecedência is a single switch and a single day count for carimbos, pontos, and cashback, because it decides when the Cliente is told, not how long the saldo lasts. The Promoção Lembrete stays on 7 days. A missed morning says the real days left, and that vencimento is told once, so a failed run is not dropped and changing the count does not send the same vencimento again.
