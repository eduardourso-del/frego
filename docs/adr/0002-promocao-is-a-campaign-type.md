# Promoção is its own Campanha type

A no-threshold Prêmio (seasonal %, BOGO, weekday add-on) is a new Campanha type `promo`, not a generalized birthday and not `stampsNeeded = 0` on stamps/spend.

Birthday is the customer’s date of birth, not the shop calendar. Zero-meta loyalty would still be a carimbo/ponto Campanha at the till. Promoção reuses Prêmio → Resgatar → Voucher → Confirmar and Audience; entitlement is calendar + frequency, not the stamps/points pool.
