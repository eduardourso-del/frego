# A Promoção Voucher is a 24h till token

Promoção keeps the same 24h Voucher TTL as stamps/birthday. Unused expiry does not restore the Resgatar quota.

We rejected a season-long rain check (that would be stored credit) and refund-on-expiry (that would turn the cap into Confirmar-with-a-delay). Resgatar is for this visit; “once this Natal” is once they tap at the door, not once they tap in November.
