# The printed Check-in promise stays

Once a Campanha de check-in has been active, the number of Check-ins that entitles the Prêmio, and the Prêmio itself, stay fixed. A stamp Campanha can still change its threshold while active. This one is printed on the tables, so a different promise is a new Campanha. It has no start and no end. Pause and archive are how it stops. The Resgatar cap stays editable, as on the other Campanhas.

## Considered Options

- **Editable while active, like the stamp threshold.** Rejected: the cards already on the tables would go stale.
